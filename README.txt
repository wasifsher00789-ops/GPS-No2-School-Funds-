GPS No.2 Multan Khurd — GitHub Pages PWA

Upload these files to the root of a GitHub repository:
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

Then:
1. GitHub repo > Settings > Pages
2. Source: Deploy from a branch
3. Branch: main / root
4. Save
5. Open the GitHub Pages URL on your phone.
6. Chrome: menu > Add to Home screen / Install app.

Firebase Realtime Database remains connected through the existing HTML.
